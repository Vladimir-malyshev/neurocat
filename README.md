# 🐾 Нейрокот / NeuroCat

Блог о селфхосте: как держать свои серверы доступными, настроенными и предсказуемыми.

Пишу о сетевой настройке, маршрутизации, диагностике недоступных серверов и ИИ-инструментах для администратора. Делюсь тем, что проверил на практике. Развиваю сервис проверки доступности IP и ИИ-консультанта по селфхосту.
